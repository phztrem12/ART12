ART12 - como rodar
1) Abra um terminal nesta pasta e rode:  python3 -m http.server 8000
2) Acesse http://localhost:8000 no Chrome ou Edge (precisa de internet para carregar o Three.js).

Personagens 3D:
- Soldado humano rigado com animações Idle/Walk/Run carregado em GLB.
- Modelo de demonstração do projeto three.js (MIT): https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf
- O modelo é carregado por CDN na primeira execução; é necessária conexão com a internet.
